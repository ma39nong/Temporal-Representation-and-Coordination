## 2. 参数预算是否公平

实际hidden为(B,7,1024)，原共享速度头1024→58。保持原头不变：

- B2：共享低秩残差`(hV)U`，rank11；1024×11+11×58=**11,902**。
- B3：共享V、每阶独立U[k]，rank8；1024×8+7×8×58=**11,440**。

统一无bias结构必须有1082r个参数。rank10是10,820，比B3少620；rank11比B3多462，更接近，因此沿用rank11。没有修改结构或填入无效参数凑整。

462为B3新增预算的4.04%，占完整可训练Expert约0.000107%。因此这是**近似新增参数匹配**，并非严格等参或只改变一个数学因素的消融：B2/B3同时存在共享/分阶、rank11/rank8及初始化矩阵形状差异。两者不能互称容量超集。即使B3胜出，也只能首先支持该预算下分阶读出的实用收益，不能单凭本轮消除秩与参数化的全部混杂。若结果相当，优先更简单的B2；不以多462个参数为由单方面改动配置。

两组U零初始化，V非零同分布、固定seed；原19叶和冻结VLM完全相同。新增矩阵不是逐元素相同。已有FP32真实Batch零残差初始化、关闭Adapter、物理动作恢复最大差均为0。BF16下仍须重新验收，不能直接继承FP32结论。残差einsum显式FP32，与原BF16主干构成混合计算；B2/B3相同精度规则，没有宣称全网络纯BF16。
