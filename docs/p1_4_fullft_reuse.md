## 判断

**Step8000确实存在、完整且可加载，值得复用；不是无效文件。** 训练来源真实RMSE为 **0.009867rad**。但“技术上有效”不等于泛化已解决：候选20窗为 **0.226701rad**，其误差98.84%仍是整体轨迹偏移。候选中两条明确是任务失败示范，另两条未拒绝却缺少成功结果证明，不能称为独立成功泛化结果。

## 4. 与P1-2哪些比较有效

| 比较 | 可解释范围 |
|---|---|
| 本轮4000/6000/8000 | 相同运行/模型/统计/505窗/精度，可描述该运行继续训练的误差变化；一次seed仍非普适学习规律 |
| 本轮Step8000 vs P1-2 B0/B2 Step500 | 相同动作单位、固定窗口和FP32协议，可描述误差大小和结构；不能归因为表示选择或训练步数单一因素 |
| P1-2 B0 vs B2 Step500 | 保留其同初始化/同采样/同预算的配对含义；与本轮FullFT绝对模型是两类问题 |
| 原训练64窗监测 vs 505窗 | 窗口集合及精度不同，数值不直接替代；训练日志内趋势只能作辅助 |
| 全部候选 vs独立成功泛化 | 不成立：质量/来源独立性未闭合，包含失败示范且已用于方法探索 |

P1-2的B2候选RMSE0.082579rad低于当前Absolute Step8000的0.226701rad，只能作为“这种探索性分布偏移下值得验证坐标迁移”的线索；不能宣称B2在公平8000步预算下胜出，也不能用两批条件不同的训练证明因果。Step8000训练来源0.009867则明显低于P1-2 B2的0.034077rad，说明两组面对不同训练成熟度；不能选择只展示候选优势。

P1-2也并非全网络随机初始化的“从零训练”：它从共同π₀.₅基础权重初始化FLASH。本轮拟议实验从**已进行8000步Absolute FLASH训练**的相同参数开始，研究迁移增量收益，不再回答基础权重起点时的学习容易程度。

## 5. 建议的同Step8000 B0/B2微调协议（仅设计）

**值得小预算验证，尚不值得直接延长到8000步或宣称B2最终有效。** 候选偏移仍强、权重完整可用，优先复用它能节省此前的学习；但没有充分成功独立来源，下一轮只能作受控迁移诊断。

B0-Finetune继续Absolute；B2-Finetune采用既有State-Relative适配层，所有58D使用合法当前实测q0，训练目标/历史共用参考，推理不取GT；不强制首步=q0。两组均加载同一个Step8000的全部VLM/Expert/projection参数，不重新初始化动作投影，不新增可训练参数。

**初始化偏置必须单列。** 绝对专家的输入投影/Transformer已经适配绝对系数分布；B2输入变为相对系数后，即使权重完全相同，Step0预测也不会相同。平移后的Flow速度监督源-目标差虽不变，网络的输入分布仍变，不能称为中性函数初始化。必须先测两组零更新表现：B0重放应复现本轮Step8000，B2记录坐标切换冲击和后续恢复。分别报告各自Step0→结束的变化与相同步数的终点，不把“从切换后崩落恢复”全部算成胜过原Absolute模型的收益。若B2只恢复但未超过B0，不支持增量收益。

| 控制项 | 设计 |
|---|---|
| 优化器初始化 | **两组均新建Adam，mu/nu/count清零，hash一致**；不只给B0恢复旧Absolute动量。原Adam已证实可读，保留供将来独立研究恢复策略 |
| 训练样本 | 原480训练来源/同manifest/原统计；两组统一data_seed42003、shuffle cursor0，完整采样序列hash一致；不计算候选统计 |
| 参数/精度 | 相同3,353,487,146参数FullFT；K6/7Token/50×58、BF16训练策略不变 |
| 随机 | model/flow42、augmentation42002；两组相同噪声key与样本对应关系 |
| 预算 | **250更新/组**，batch256/8GPU，64,000窗口/组；0/50/100/250保存并评价。100仅看是否能适应，不宣布优劣；500是以后条件允许再决定的上限，不自动执行 |
| 优化器/LR | 原AdamW超参数；两组同25步warmup、peak2.5e−6、之后恒定至250。属于预注册提案，不通过候选20窗挑选LR |
| Loss/架构 | 原FM+Consistency及权重不变；仅坐标及必要配套变换不同，不加局部/协调loss或额外Expert |
| 评价 | 本轮相同505窗、FP32/highest/NFE1/batch1，全部还原Absolute rad；训练/未拒绝成功未核实/失败来源分列；保留每来源和末9步、偏移/形状/尾部 |
| 运行约束 | 短步save/restore检查计入各自250步；OOM/NaN停止受影响试验，不单改一组配置 |
