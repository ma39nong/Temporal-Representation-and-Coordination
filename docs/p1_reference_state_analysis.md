# P1-1：参考状态q0的物理意义

日期：2026-11-06。复用封印的同一505窗GT/history和4000/6000预测；不重新做数据审计或新抽样。97训练来源485窗与4候选来源20窗分别统计，后者原始bag独立性仍未完全证明。

## 结论

q0是合法当前实测关节位置，可作为四组动作的**坐标参考**；不是要求策略必须经过的命令目标。按已核验名称与rad单位，未发现action/state位置速度混淆或手臂顺序错误。机械臂和手的反馈—命令差异不同，尤其右手两个MCP-AA关节存在稳定的非零残差。B2须学习 `A_gt−q0` 的真实值，不能强制首步为0或用未来反馈构造参考。

物理兼容性限定为当前数据与原协议下的同名位置量，不包含机器人标定、硬件端到端时间或实际动作成功的证明。

## 命令是否领先反馈？

新增的只读离线诊断覆盖固定505窗对应的全部101条record。对每条record、每组，比较 `A[t]` 与 `S[t+lag]`，lag∈[-10,10]，所有lag使用同一中间时段，避免不同边界样本改变结果；另外比较相邻差分的去均值相关性。正lag表示命令序列更接近后续反馈。未来state只用于这项**事后诊断**，不传给模型。

- 训练来源Right Arm的差分相关最佳lag：94/97来源为+2帧，另外为+1/+3；4候选来源均+2帧。
- 训练来源Left Arm以+3帧为主（60/97），候选3/4为+3、1/4为+2。
- 训练手部最佳差分lag更分散，Left Hand含0、1、2及更大lag，Right Hand常见+2，也有+8/+9。候选Left Hand为+1/+2，Right Hand为+2/+3。
- 位置RMSE最佳lag与差分相关最佳lag常不同，例如训练Left Arm位置拟合多为+7/+8，而动态相关多为+3。静态偏差、平滑和动作频率都会影响拟合，不能把二者之一直接宣布为硬件延迟。

在30Hz网格上+2/+3对应约67/100ms的相关时移，但不等于测得的传输/执行延迟。缺少各topic原始发送/接收时钟及控制事件，不能确定动作超前来自控制响应、重采样、标注时钟还是其他动态。没有证据允许直接移动数据标签。尤其不能把 `S[t+lag]` 当推理时q0，这会泄漏未来反馈。

## 状态参考会不会放大异常？

物理可逆平移本身不改变固定轨迹的时间差分，也不增加系数预算；反变换用同一个q0恢复。若q0有测量误差，它会移动整条残差目标的原点；模型是否鲁棒仍需实验，不能用数学往返正确代替数据可靠性。

B2归一化保持原训练action Quantile跨度，选中关节使用 `2*(A−q0)/(q99−q01+eps)`，不重估候选来源统计、不clip残差。训练来源各组归一化残差最大绝对值约1.204/1.783/.733/2.623，候选约1.094/.910/.251/1.501（LA/LH/RA/RH）。超过1不表示无效数据：这些是相对值，非原Absolute分位范围约束。逐关节跨度与极值已输出，可定位小跨度/异常q0问题，不通过删掉大残差制造收益。

已有B1证据继续适用：强制P[0]=q0将训练来源RMSE从.011727恶化到.036567 rad，尽管候选来源有所改善。因此本轮不添加首步等式约束、延迟补偿、接触规则或新损失。

输出两种明确不同的分层：Episode首个**保留帧**状态，以及当前评价窗口q0。以训练数据各关节均值/std定义RMS标准化距离，训练分位P50/P90切为low/middle/high；std floor=1e-6，仅用于诊断，不改变模型归一化。

| 分层基准 | 训练参考数量 | P50 / P90切点 | 候选窗口low/middle/high |
|---|---:|---:|---:|
| Episode首个保留帧 | 480个训练Episode | .755389 / 1.437751 | 10 / 10 / 0 |
| 窗口当前q0 | 485个训练窗口 | .902646 / 1.379138 | 0 / 6 / 14 |

这再次表明候选Episode起始机械臂接近既有训练起点，而任务过程中的状态更偏离训练窗口分布；不能把过程差异说成原始初始化变化的因果证据。分层中的窗口仍有重叠，同source多窗不独立，4候选来源没有支撑充分泛化或显著性结论。
