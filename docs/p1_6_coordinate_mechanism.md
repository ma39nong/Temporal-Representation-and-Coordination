## 2. 四条路径的确切定义

记原动作归一化 `F(a)=2(a−lo)/s−1`，`s=hi−lo+1e−6`；原重建为 `L(C)=B diag(scale) C`，反归一化 `G(x)=s(x+1)/2+lo`。令 `S=fit_history(F(history))`，`Q`为常量多项式系数，满足 `L(Q)=F(q0)`，只改变零阶系数，且除以原 `scale[0]`。设固定视觉语言条件下的一步Expert速度为 `v`。

| 路径 | Expert Flow Source | 输出系数（进入原Absolute解码器） |
|---|---|---|
| D0 Absolute历史 + Absolute输出 | S | S+v(S) |
| D1 Relative历史 + Absolute输出 | S−Q | S−Q+v(S−Q) |
| D2 Absolute历史 + Relative输出恢复 | S | S+v(S)+Q |
| D3 Relative历史 + Relative输出恢复 | S−Q | S+v(S−Q) |

这里“Relative输出恢复”意味着把原网络系数解释为相对坐标，再加回同一Q；它与先做相对坐标的斜率反归一化、再加物理q0等价。不能直接在归一化系数上加物理q0。

令 `u=q0−m`，`m=lo+s/2=(lo+hi+1e−6)/2`，则严格有：

```text
D2 = D0 + u
D1 = D3 - u
D3 - D0 = (s/2) L(v(S-Q) - v(S))
D3 - D1 - D2 + D0 = 0
```

因此D2确实等价于固定输出的常量平移，但平移量是**相对归一化中心的状态位置u，不是q0**，也不是 `q0−P[0]`。D3最终的显式参考项与Flow Source中的−Q抵消，剩下的是同一网络对不同系数输入的响应差；不能把D3称为“给原预测加q0”。没有强制首步命令等于反馈，没有用未来GT求校正量。

## 4. 收益分配与交互：不能只给一个百分比

定义历史输入变化 `H=D1−D0`，输出恢复变化 `U=D2−D0=u`。物理动作的二阶差 `D3−D1−D2+D0` 最大仅 **4.441e−16 rad**，没有额外函数交互项。但是平方误差的交互严格为：

```text
I_MSE = MSE(D3)-MSE(D1)-MSE(D2)+MSE(D0) = 2 mean(H*U)
```

| 来源 | D1−D0 MSE | D2−D0 MSE | D3−D2 MSE | I_MSE |
|---|---|---|---|---|
| 训练 | +0.071128919 | +0.068768074 | −0.067227890 | −0.138356810 |
| 未拒绝候选 | +0.040410736 | −0.028685297 | −0.024546277 | −0.064957014 |
| 失败示范 | +0.045061646 | −0.010357426 | −0.030089315 | −0.075150961 |

“只改历史会变坏”和“在恢复输出后改历史有额外收益”可以同时为真，因为输出解释不同。D1不能用于否定所有历史输入作用，D2也不能代替D3。

若沿D0→D2→D3这一条路径分账，D2的MSE改善占总改善：未拒绝候选 **53.89%**、失败示范 **25.61%**，合计仅作代数核对为 **41.68%**；其余分别由该路径下的历史输入变化补足。换另一条路径会得到不同分账，不能声称“输出固定贡献41.68%，历史固定贡献58.32%”是唯一因果比例。

冻结流程：

1. 新录制按原始recording登记，记录原始录制SHA、全部祖先ID、清洗/裁剪/转换谱系和原始时间映射。核对完整训练注册表、旧候选和其他已用于选择方法的来源；ID不同不代表独立，别名或转换副本同样排除。登记表需证据文件hash与人工审核记录。
2. 成功/失败/未核实先于模型评价登记。正式主测试只纳入审核通过的完整成功任务；失败任务单独作为failure-mode集合；未核实任务不进入正式成功测试。记录初始位置、果串构型、左右臂手状态分布和质量检查，不根据误差改变分类。
3. 沿用原LeRobot reader、58D schema、30Hz和连续段审计。合法窗口要求同一有效段内支持history[-7,0]与target[-2,51]；检查整个[-7,51]范围的有效mask，不跨Episode/裁剪边界。q0取history最后一帧；truth为target_ext[2:52]，不强制q0=truth[0]。
4. 本轮预定每原录制在全部合法位置上均匀选5窗，选择不读模型预测；完整任务审核覆盖全录制。若未来改为全窗口评价，必须在正式锁定前更换协议版本，不能按结果选择窗口。
5. 相机三路features必须与冻结配置匹配，另需审核同步、裁剪映射、RGB来源和原始预处理。使用原NativeDataset入口确认选中RGB逐帧hash和时间对应关系；数值reader自身不声称验证了视频同步。

## 7. 对P2的判断：先研究状态条件利用，不批准架构扩展

1. **纯输出变化能否解释主要改善？** 可以解释一部分，不能解释全部：D2平均低于D0，却仍远差于D3，且一个失败来源方向相反。不能把旧候选上的平移抵消解释为新泛化能力。
2. **相对历史有无额外收益？** 在相对输出恢复这个条件下有：D3优于D2，训练97来源和候选4来源均如此；单独D1则全面退化。改变的是原Expert看到的Flow Source系数，视觉语言前缀没有变化，并非增加信息或参数。
3. **是否稳定？** 旧候选的D3优于D0方向一致，训练来源却97/97退化；P1-2基础权重学习和P1-5成熟权重迁移是不同问题，不合并为同一学习结论。旧候选已被反复使用，不能检验稳定的独立收益。
4. **是否支持参考位置/局部动态分解研究？** 支持把它作为误差诊断方向：主要差异确在偏移，但训练形状与尾部也受损；没有证据证明分开生成比现有单Expert更好。
5. **是否应改Expert内部结构？** 目前不应。没有新的可靠FK、操作事件或执行日志，不能归因为跨臂手协调失败，也不支持新的协调损失。

只保留一个待独立验证的最小方法候选：**同一Expert的双坐标物理输出一致性约束**，先研究参考状态条件利用的鲁棒性，不更换架构。它针对的是已观察到的“相对Flow Source改变既有分布函数，造成97来源退化”；现有B2只监督相对坐标，没有要求同一合法状态下两种输入坐标解码后都可靠。

候选数学形式为同一参数θ、同一合法观测/history构造 `P_abs=G(L(S+vθ(S)))` 与 `P_rel=G(L(S+vθ(S−Q)))`，在**训练来源**上加配对物理一致性项 `mean((P_abs−P_rel)²)`，同时保留匹配的原FM/Consistency监督。共享原7Token/K6/50×58和完整参数；没有两个Expert，没有跨臂协调loss，没有新信息。需要触及的只是显式研究适配器的训练loss接口；本轮不实现、不设最终权重、不启动训练。

最小公平消融必须同时包含原B2和不加该一致性项、但采用相同双分支计算/采样监督的控制组，控制参数量、初始化、样本、步数、优化器和额外前向计算预算。权重只在新的训练/开发来源选择，正式独立锁定集不参与。其风险是把两种路径强行拉向已有Absolute行为，消除候选收益或压制局部动态。若训练来源可靠性不恢复，或只通过消除候选收益来满足一致性，或独立成功来源无改善/局部尾部变差，该候选应被否定。该方案目前只是有据可证伪的条件利用研究提案，不宣称新颖性或必要性；新独立数据未闭合前，不进入正式P2架构开发。
