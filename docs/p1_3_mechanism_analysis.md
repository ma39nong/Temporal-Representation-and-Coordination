# P1-3：B0/B2 收益机制与退化案例分析

日期：2026-11-07。起点 `main@e32fc44`。本轮只读复用 P1-2 的真实封存预测；没有训练、延长训练、修改原工程/数据/Checkpoint、机器人控制或远端推送。

## 研究判断

**NEED MORE EVIDENCE。** B2 的平均收益主要来自整体轨迹偏移下降，不能外推为局部动作变化、所有来源或所有尾部都改善。证据足以提出一个可证伪的最小优化机制候选，但还不足以认定需要新的 Expert 架构，更不支持协调损失或“已解决双臂协作”。本轮不实现新算法。

Step500 的训练来源总 MSE 收益中 **92.47%** 来自时间平均偏移下降，候选来源为 **98.65%**。但 8 个退化训练来源的偏移 MSE **全部增加**，其中只有 3 个来源的整体形状 MSE 增加。这说明退化并非统一的“形状被破坏”，首先是某些来源仍存在偏移预测回退。同时，左臂晚段误差与相邻步变化误差退化，证实整体平均会掩盖局部问题。

这些是对保存预测的代数归因和描述性证据，不是对网络内部学习过程的因果证明。B2 的可逆平移不增加信息、参数或多项式表示容量；同坐标平移后的历史源与目标之差不变。不能声称它直接减少了 Flow 速度监督量、保证保留局部形状，或已经构成学术创新。

### 系数误差与动作贡献必须区分

沿用原样本上的50×7 basis `B`、训练系数 scale `s` 及关节quantile物理尺度 `h_j=(q99_j−q01_j+1e−6)/2`，每阶动作残差为：

`R_m,k[n,t,j] = B[t,k] s[k] h[j] (C_m[n,k,j]−C_gt[n,k,j])`。

未经加权的系数 MAE/MSE 不是动作空间重要性。50点评价只截取54帧监督中的0…49，有限采样下不同阶并不严格正交，各阶独立能量不能直接相加。旧 [coefficients.csv](../outputs/p1_2_pilot/report/coefficients.csv) 保留每阶scaled/raw-normalized/raw-physical误差；[coefficient_contributions.csv](../outputs/p1_2_pilot/report/coefficient_contributions.csv) 保留独立解码能量和交叉项。

本轮进一步计算**最终 GT 误差改善量**的有符号分配。设 `S_m=P_m−Oracle`、`g=Oracle−GT`，则

`G_k = mean(R_0,k S_0 − R_2,k S_2 + 2g(R_0,k−R_2,k))`。

各阶共享交叉项，并单独保留浮点解码残差分配；`sum(G_k)+G_roundoff=MSE_B0−MSE_B2`。不能把负贡献截为0，也不能将这种代数分配当成某阶的因果贡献。所有来源/组/步的求和检查通过；最大解码残差7.60e−7 rad。

## 5. 对P2的设计依据与边界

| 问题 | 当前可支持的判断 | 仍不能支持 |
|---|---|---|
| A 整体参考坐标预测 | 平均收益主要为偏移改善；8来源偏移仍回退 | q0不兼容是统一根因；已证明所有状态分布泛化 |
| B 局部形状预测 | 左臂晚段/增量及部分手关节极尾存在可复现退化 | K6表示不足；必须增加阶次/参数；有确定操作阶段失败 |
| C 跨臂手关系 | 只观察到分组/关节/时间误差异质性 | 缺少FK、可靠事件与实机结果，不能确认协调损坏 |
| D 新Expert设计 | 能提出一个最小、可证伪的优化机制假设 | 尚不足以确定新架构、RA-L新颖性或充分训练后收益 |

### 唯一保留的候选：以物理时间均值/形状解耦的Flow坐标预条件

**针对问题。** B2只把合法q0作为坐标原点，仍不能独立控制预测时间均值与局部变化的学习；训练左臂晚段/相邻步退化，而多数MSE收益集中于均值。候选仅检验“系数坐标/优化度量是否让形状学习被偏移和采样非正交性掩盖”，不把它预先认定为真实原因。

**数学机制。** 在原54帧拟合之后，取实际50步解码矩阵`F=B diag(s)`；令`μ=mean_t(F)`，`H=I−11ᵀ/50`。对B2相对系数c，第一模式为未来相对轨迹时间均值`m=μc`，其余6模式为`HF[:,1:7]c[1:7]`的满秩形状坐标。只用训练统计及固定basis构建可逆线性变换`z=T c`，以采样物理Gram矩阵（含关节quantile尺度）对形状6维预条件，保持总共7个Token、K6和58D输出；明确保留并记录各尺度。未来时间均值只用于训练监督，推理仍根据合法观测预测它，不从GT提取。T必须可逆且验证50步轨迹/导数不变，不做截断、裁剪、强制首步=q0或增加表示容量。

对历史源、扩展目标、混合系数、速度输出统一使用T；历史噪声也必须作`T ε`以保持同一物理噪声先验，不能换成新的各向同性z噪声后把先验变化混入收益。推理积分在z中进行，`T⁻¹`后复用原解码。以恒等权重的z空间FM/Consistency度量训练，相当于原系数空间的显式`TᵀT`度量；这是需要单独控制的优化变化，不能假称与B2原loss等价。

**改动位置。** 仅考虑研究仓库`flash_openpi.py::loss_from_cache`、`sample_coefficients_from_cache`的系数输入/速度及`FlashCoordinates`旁的固定变换；原`polynomial.fit_history/fit_target`、VLM条件与KV cache、Transformer层、投影形状、原解码不变。本轮未实现，也不引入双Expert或新的协调损失。

**与已有工作的关系。** [FLASH](https://arxiv.org/abs/2605.15492)使用Legendre连续轨迹与历史系数启动Flow；本候选保留这些机制，研究原生7模式的条件预测/优化度量，不重写FLASH。[ProAct](https://arxiv.org/abs/2610.09170)以仅动作数据训练的policy-agnostic tokenizer增强可预测性与鲁棒性；这里不训练离散tokenizer，直接诊断观察条件下的连续Flow坐标。[Coordi-π](https://arxiv.org/abs/2610.19753)显式交错左右侧arm–hand token并用身份/时间位置编码；本候选不拆左右侧Token、不增加身份编码，也不宣称改善协调。这是机制定位，未完成足以宣称新颖性的全面检索；若仅等价于常见预条件/加权loss，应作为优化基线而非RA-L核心创新。

**最小消融。** 下一轮先预注册并比较：原B2；仅显式`TᵀT`度量但保留原坐标；完整T坐标+相同物理噪声先验。三者同初始化、数据/采样、7Token/K6/参数量、优化器/更新预算、seed及Absolute评价；所有FM与Consistency项的度量变化均显式记录，禁止同时添加其它loss。训练集固定变换和尺度不使用候选20窗选参；增加预注册重复seed与真正未用于探索的成功来源验证。主要指标为来源级偏移/形状、左臂tick41–49与增量误差、P99/P99.99，设总RMSE不明显损害的约束，阈值/分析方案在看新结果前确定。

**证伪。** 若相同预算下形状/增量/极尾不改善，或只在已看过候选20窗改善、损害其它来源偏移，否定该机制的实用价值；若效果完全由度量控制解释，否定“新坐标机制有额外收益”的主张。若后续B2充分学习后局部退化自然消失，则应优先解释为小预算优化动态，停止将其包装为结构瓶颈。本轮不启动这些训练。

不保留第二个协调机制：当前缺少足够的FK/事件/执行证据。先从已经观察到的偏移回退与局部时间变化入手，不能为了论文方向制造跨臂关系问题。
