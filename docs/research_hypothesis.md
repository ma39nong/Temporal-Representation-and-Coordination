# 研究方向：Predictable and Coordination-Aware Action Generation for Bimanual Dexterous Manipulation

当前优先研究问题：为什么连续轨迹表示重建误差较低，而Action Expert仍可能产生较大预测误差；这些误差是否影响关节组间时间关系？先依次量化表示误差、预测差异和最终动作误差，再决定Action Expert改造目标。下面的异构表示假设保留为后续候选，不预设为当前瓶颈。

平台为双FR3（14D）与双Sharpa（44D），三路RGB，现有π₀.₅动作窗口50×58。当前P0仅研究离线示范的轨迹表示能力，不修改Action Expert，不训练，也不做控制。RA-L是目标投稿方向，尚无论文实验结论。

假设H：在固定时间跨度、采样点、轨迹坐标系和总系数预算下，按关节分组或阶段分配不同时间表示容量，可以改善未见示范轨迹的重建精度，尤其是跨手协调及接触阶段的峰值误差。不同关节/阶段时序复杂度不均匀是待测命题，不作先验结论。

零假设：统一阶数在同预算下已足够，异构分配无稳定收益。六阶Legendre每关节7个系数，58D单段为406个；所谓“六阶”不等于6个系数。

已有方法的关系见references.md：FLASH提供多项式轨迹表示的直接参照；Coordi-π显式组织左右手交互；RTC处理跨窗口实时连续性；MambaAct关注动作专家效率；T-Rex关注触觉与多速率结构。P0不会复现其策略成功率或据此假定本假设成立。

可证伪标准（需在P0-B冻结）：在相同预算的recording独立测试集上，异构方法对均匀基线的配对误差改善95% bootstrap置信区间未支持预注册的实际收益阈值（建议主指标5%，在看测试集前决定），或收益被更多系数/更密采样/测试阶段标签泄漏解释，则不能支持H。若仅少数阶段收益而整体无收益，应缩小主张。若动作重建更好但关键协调指标恶化，不能称双臂灵巧操作改善。

失败原因包括：示范动作本来平滑、短窗口不需高阶；接触高频来自噪声或时间错位；归一化制造虚假复杂度；阶段切割产生不连续；分组弱化跨手协同；非平稳Delta锚点混用；阶段标注不可在线获得；单颗番茄数据不能代表连续多颗任务；同源episode跨集合泄漏；系数预算漏算边界/共享项；容量最优不代表模型可学习或可部署。离线拟合是表示上界，不等同于闭环成功率。
